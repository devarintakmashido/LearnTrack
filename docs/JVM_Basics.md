## JDK
Java Development Kit contains tools required to develop Java applications
such as the compiler (`javac`) and runtime tools.

## JRE
Java Runtime Environment provides libraries and JVM required to run Java programs.

## JVM
Java Virtual Machine executes Java bytecode and provides platform independence.

## Bytecode
Java source code is compiled into bytecode, which is executed by the JVM.

## Write Once, Run Anywhere

“Write once, run anywhere” means that a Java program can be written on one system
and executed on different operating systems without changing the source code.
This is possible because Java source code is compiled into an intermediate form
called bytecode, not directly into machine-specific code.

The bytecode is executed by the Java Virtual Machine (JVM), which is available
for different platforms such as Windows, Linux, and macOS. As long as a system has
a compatible JVM installed, the same Java program can run on it, making Java
platform-independent.
